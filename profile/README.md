<h3 align="center">haaku</h3>

<p align="center">
  Keep tabs on everything you watch — watch history, scrobbling, ratings, lists and social, on a server of your own.
</p>

<p align="center"><a href="https://haaku.tv">haaku.tv</a></p>

---

> **把握** — *haaku*: “to have a handle on; to keep tabs on a situation.”
> The word Japanese speakers use for the whole picture of where things stand — which is exactly what a tracker does.

---

### Repositories

| Repository | Description |
|------------|-------------|
| [haaku](https://github.com/haaku-tv/haaku) | Keep tabs on everything you watch: Go API + embedded React UI in one binary, with its own PostgreSQL and Redis |
| [haaku-jellyfin](https://github.com/haaku-tv/haaku-jellyfin) | Jellyfin plugin that scrobbles and syncs your watch state to a haaku instance |
| [tkiller-design-kit](https://github.com/haaku-tv/tkiller-design-kit) | The design system behind the haaku frontend |
